Day 2 — Adapter trainer (streaming LoRA) (6–8 hrs)
Goal: Train tiny LoRA adapters using streaming input; must run on 4050/3080 with 8-bit.

1. Create adapter_service/train_adapt.py — behavior:
◦

Load base model (configurable) via --model_name_or_path.

◦

Stream N samples from mcp (use --max_train_samples, default 2000).

◦

Use bitsandbytes + peft LoRA with 8bit=True.

◦

Use --gradient_accumulation_steps to fit VRAM.

◦

Save adapter to adapters/<lang>_lite.

2. Example run command:
python adapter_service/train_adapt.py \
--model_name_or_path "gpt-small-base" \
--adapter_out adapters/awadhi_lite \
--stream_source "mcp:wiki_awadhi" \
--max_train_samples 1500 \
--num_epochs 3 \
--per_device_train_batch_size 1 \
--gradient_accumulation_steps 8 \
--use_8bit True
3.

Add adapter_service/model_utils.py to load base model + apply adapter at inference.

4.

Commit & push.

Acceptance Day2: One adapter trained for one low-resource language (e.g., Awadhi); saved under
adapters/awadhi_lite.
