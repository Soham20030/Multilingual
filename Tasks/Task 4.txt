Goal (one line): Attach KSML semantic tags to every multilingual output, enable live RL policy
updates from streamed MCP feedback, and publish InsightFlow telemetry — all under <1s latency
on RTX 4050.

Deliverables (must-have)
1.

KSML Aligner Service

•

FastAPI: POST /align.ksml → returns { text, ksml: {intent, source_lang, target_lang,
karma_state, roots[]}, confidence }

•

Lightweight Sanskrit-root tagger using ksml/ksml_roots.json (lookup + heuristics).

•

Intent detector: rule+keyword + tiny classifier (optional).

2.

RL Live Policy (Bandit → PPO-ready)

•

Endpoints:
◦

POST /rl.feedback → {prompt, output, reward, lang, trace_id} (updates local Qtable/bandit).

◦

GET /rl/policy → dump current policy snapshot.

•

Local updates (bandit/Q-table) + episode log to NAS/S3 for cloud PPO.

•

CLI: python rl/collect.py --source http://…/bridge.reason --upload s3://…/episodes/.

3.

MCP Feedback Stream

•

mcp/stream_client.py pulls (prompt, target, correction) from Core/Bucket or web feeds.

•

Writes to data/feedback_stream.jsonl and feeds RL collect.

•

Supports at least 10 languages live (from your 34 set).

4.

Speech-Ready Composer for Vaani

•

POST /compose.speech_ready → { text, lang, tone, prosody_hint } mapped to Karthikeya’s
schema.

•

Confirm tone keys & test 10 samples (EN/HI + 3 Indic).

5.

Multilingual Reasoning Bridge

•

POST /bridge.reason → calls Bhavesh’s /compose.final_text → runs KSML aligner → RL
feedback → returns { final_text, ksml, prosody_hint }.

•

Logs to /logs/ksml_bridge.jsonl with trace_id, policy version, reward.

6.

InsightFlow Telemetry Hooks

•

Emit: latency, policy_version, reward_avg, lang_drift, cache_hit.

•

Fallback stub if InsightFlow offline.

7.

Docs + Smoke

•

bridge/tests/smoke_results.md across 10 languages (latency, pass/fail, ksml coverage).

•

README with curl examples, runbook, HDIG reflection.

Non-functional constraints
•

Latency: end-to-end ≤ 2s; avg per call ≤ 1s on RTX 4050.

•

VRAM: ≤ 4 GB.

•

Security: Supabase JWT check on all POSTs; no secrets in repo.

•

Logs: JSONL with trace_id, user_id (if present), timestamps.

•

Storage: episodes to NAS/S3 (use Yaseen/Karan credentials).

•

KSML coverage: ≥ 85% fields populated on smoke set.
